# Земля для команды

Веб-версия CRM для распределения откликов с Авито. Администратор загружает Excel, отмечает карточки и назначает ответственного. Каждый сотрудник входит под своим логином и видит назначенные ему карточки. Изменения статусов и заметки сохраняются в общей базе.

## Первый запуск

1. Распакуй архив. Для запуска нужен Node.js версии 24. Дистрибутивы для macOS, Windows и Linux доступны на [сайте Node.js](https://nodejs.org/en/download).
2. На Mac открой файл **Start-Zemlya.command**. На Windows или Linux открой терминал в распакованной папке и введи `node server.mjs`.
3. Открой в браузере [http://127.0.0.1:3080](http://127.0.0.1:3080). При первом запуске в окне сервера появится одноразовый код. Введи его на странице настройки и создай аккаунт администратора.
4. В разделе **Сотрудники** создай аккаунты по рабочей почте. CRM один раз покажет временный пароль. Сотрудник задаёт свой пароль после входа.
5. Нажми **Загрузить отклики**, проверь сопоставленные поля и подтверди импорт. Отметь карточки и нажми **Назначить сотрудника**. Один лид можно передать из его карточки. Получатель увидит его в **Моих лидах**.

Для переноса из прежней CRM скачай JSON через **Резервная копия → Скачать копию** и выбери **Восстановить из копии** в командной версии. Excel-импорт и JSON-перенос сохраняют сопоставление известных лидов.

## Одна ссылка для сотрудников

Для постоянного доступа разверни распакованную папку на одном сервере с Node.js 24. Настрой домен и HTTPS. Веб-прокси должен направлять запросы на `127.0.0.1:3080`. Запусти CRM с переменной `ZEMLYA_ORIGIN`, равной полному адресу этого сайта, включая `https://` и без завершающего слеша. Пример для Linux или macOS:

```sh
ZEMLYA_ORIGIN=https://crm.example.org node server.mjs
```

Укажи свой адрес вместо `https://crm.example.org`. Держи процесс запущенным, например через менеджер служб сервера. Для сотрудника достаточно адреса сайта и своего аккаунта.

По умолчанию SQLite сохраняет данные в папку `data` рядом с местом запуска. Для полного переноса команды с аккаунтами и назначениями останови CRM и перенеси всю папку `data`. JSON-копия из интерфейса служит для переноса карточек и истории импорта.
